# Type reveal/exit styles (generated)

Use any style for entrance or as `exit.style` (the style is played in reverse). Splitting: `by:"chars"` for short punchy words, `"words"` for phrases, `"lines"` for paragraphs. Styles marked *mask* need `Type.make(el,text,{mask:true})`.

| style | description |
|---|---|
| `fade` | plain opacity |
| `fadeBlur` | fade in from a blur (calm, cinematic) |
| `slideUp` | rise from a mask line (needs mask) |
| `slideDown` | drop in from above a mask line |
| `slideRight` | wipe in from the left edge of a mask |
| `riseFade` | small rise + fade (editorial) |
| `slam` | scale down from huge with overshoot |
| `pop` | spring pop from 0 (playful) |
| `rotateIn` | tilts in from rotation |
| `flip3d` | flips up around X axis (3D) |
| `flipY` | card flip around Y axis |
| `dropBounce` | falls from above and bounces |
| `elastic` | stretches like rubber and settles |
| `trackIn` | letter-spacing collapses (whole line) |
| `weightMorph` | variable weight 100→900 (needs variable font) |
| `widthMorph` | variable width 62→125 (Archivo) |
| `scramble` | decodes random glyphs into the text |
| `typewriter` | types in with a caret (use by:chars, stagger .04) |
| `blurFocus` | sharpens from heavy blur + scale (hero) |
| `wave` | letters rise in a wave and settle |
| `stretchIn` | scaleX from 0 (bars, underlines, tags) |
| `maskWipe` | clip-path wipe left→right |
| `maskWipeUp` | clip-path wipe bottom→top |
| `splitReveal` | two halves slide apart to reveal |
| `glitchIn` | jittery RGB-split glitch in (digital) |
| `zoomThrough` | starts huge and pulls to place (camera through the letter) |
| `swing` | hangs and swings into place (words) |
| `cascadeSides` | alternate words enter from left/right |
| `inkFill` | outline draws, then fills (stroke→fill) |
| `shuffle` | letters swap positions into place |
| `stampDown` | stamps down hard with a tiny rebound |
