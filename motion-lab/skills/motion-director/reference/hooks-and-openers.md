# Hooks and openers (frame 0-30)

All strong short-form references show a strong shape, number or movement in frame 0-10. None opens on black or a logo.

| Hook | Recipe | Needs |
|---|---|---|
| Giant numeral | number 4-8x body size already counting; half hidden by an object | kinetic-typography |
| In-motion shape | a shape mid-flight settles into the title position | Lab.curves.punch |
| Question hook | one lowercase question, huge, with the first word already on screen at frame 0 | |
| Break the frame | letters cropped by the frame edge, camera pushes to reveal the rest | |
| Impossible object | glass/clay object that rotates once, then speaks | generative-3d-backgrounds |
| Cursor hook | cursor already moving toward a button; click at 0.8 s | ui-in-video |
| Reverse hook | show the result first (finished UI/art), then peel back | |
| Pattern hook | rhythmic pattern (dots, bars) pulsing on the beat, then it breaks into the title | motion-canvas-artwork |
| Flash hook | white flash frame 0-2 then reveal | transitions |
| Silence hook | everything holds still for 0.4 s then one hard hit | sound-design-pro |

## Rules
1. First visible change within 0.2 s; first sound within 0.5 s (sound gate: first sound <= 0.25 s ideal).
2. The hook image must be IN the video later (callback), not a separate teaser.
3. Do not explain in the hook: show.
4. Opening text <= 6 words.
5. If the platform crops the top 220 px and bottom 360 px, keep the hook inside y 220-1560.

## Closers
| Closer | Recipe |
|---|---|
| Loop | last frame equals frame 0; sound `loop-point` |
| Payoff line | 3-6 words, hold 1.2 s, soft impact |
| End card | dark card, name/handle (user-supplied only), small |
| Callback | return to the hook image transformed |
| Cut on a beat | hard cut at the end of the last bar with no fade |
