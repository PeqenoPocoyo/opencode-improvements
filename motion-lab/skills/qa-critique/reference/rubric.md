# Critique rubric (score each 1–5; ship only if every line ≥ 3 and the total ≥ 28/40)

Look at the contact sheet and the pacing strip, then write ONE sentence of evidence per line.

| # | Dimension | 5 looks like | 1 looks like |
|---|---|---|---|
| 1 | **Hook (0–1 s)** | motion + a clear subject in frame 1; sound hit at 0–0.3 s | black/empty start, slow fade, logo first |
| 2 | **Concept** | one idea you can say in a sentence; every scene serves it | collection of effects |
| 3 | **Hierarchy** | one obvious focal point per frame; 3 type sizes max | everything same size/weight |
| 4 | **Legibility** | text ≥ 20 px @1080 and high contrast; safe zones respected | tiny, low contrast, cut by UI chrome |
| 5 | **Motion quality** | varied eases per intent; overlap/anticipation; settle; no linear | one ease; everything enters together |
| 6 | **Rhythm/timing** | cuts and hits on the same grid; breathing room; ends on a held payoff | arbitrary durations, no holds, no accents |
| 7 | **Distinctiveness** | palette/type/texture unmistakably from this DNA; differs from previous video | same purple gradient + Inter + fade-up |
| 8 | **Craft & finish** | grain/vignette, consistent radii/shadows, pixel-clean edges, depth | flat, default shadows, jaggies |
| 9 | **Sound** (by report) | layered hits aligned ±1 frame, loudness in range, no clipping | silence, mush, or clipping |
| 10 | **Polish of the ending** | clean last frame, loop-safe or clear CTA | cut off, mid-motion |

(Rows 1–8 are 5 pts each = 40 with 9–10 optional extras for audio/ending. Use 8 rows for silent videos.)

## How to write the critique (format the model must use)
```
VERDICT: ship | revise (pass N/3)
TOP 3 PROBLEMS (most visible first), each: where (timestamp/scene) – what – fix (specific parameter/code change)
KEEP: 2 things that work (do not touch)
```
Never write "looks good" without evidence from the sheet. If you cannot name a timestamp, you did not look.
