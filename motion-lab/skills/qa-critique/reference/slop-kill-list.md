# Slop kill list — the tells of an AI-made motion video (search your output for each)

## Visual
1. Purple/indigo → cyan gradient background (the stock AI palette). Replace with the DNA colour story.
2. Centered title + subtitle on a dark gradient with floating blurred orbs.
3. Glassmorphism cards for everything, same radius, same blur.
4. Everything fades up 20 px with the same ease, same stagger, same delay.
5. Emoji as icons. Use the UI.icon set / drawn shapes.
6. Drop shadows on everything; neon glow on everything.
7. Perfectly symmetric layouts with no tension (no cropping, no scale contrast).
8. Stock "tech" copy ("Supercharge your workflow", "Unlock the power of…"). Write specific, concrete copy with numbers/names.
9. Lorem/placeholder data, round numbers, "John Doe".
10. Particles floating aimlessly "for atmosphere".

## Motion
11. `ease-in-out` everywhere; no overshoot/settle; no anticipation; no hold.
12. Whole-screen cross-fades between every scene.
13. All elements animate simultaneously (no stagger/priority).
14. Constant slow zoom on static images as the only camera.
15. Spinning/rotating things with no reason.
16. Text reveals identical for hero and support lines.

## Timing & sound
17. Equal scene lengths (3 s, 3 s, 3 s…).
18. Sound effect placed at the start of a transition instead of its peak; same whoosh for every cut; no silence before the drop.
19. Music bed with no relationship to the cuts; no accent on the key word.
20. No hold on the payoff frame (the viewer never reads it).

## Fix procedure
For each tell found: name it → pick a replacement from the pack (DNA palette, `Lab.curves`, `Lab.stagger`, `transitions-projections`, `kinetic-typography` style table) → change → re-render stills.
