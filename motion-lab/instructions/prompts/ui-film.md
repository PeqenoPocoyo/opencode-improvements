# Prompt: filme de produto / interface de app em vídeo

Use `skills/ui-in-video` (+ `style-dna`, `kinetic-typography`, `transitions-projections`, `sound-design-pro`). Produto: [NOME + O QUE FAZ]. Funcionalidade a mostrar: [FEATURE]. Formato [9:16 / 16:9], [DURAÇÃO] s.

1. Escreva a história em 5 beats (contexto, foco, ação, resultado, saída) com tempos.
2. Defina conteúdo REAL da interface: nomes, 3 números que contam uma história, textos específicos (nada de Lorem/“John Doe”/números redondos).
3. Gere DNA e mapeie `UI.theme(...)` a partir dele (não use o tema azul-escuro padrão se o DNA não for assim).
4. Monte com `UI.window/browser/phone` + componentes; cursor com arco e clique; câmera com punch-in no foco; transições entre telas via `UI.pages` ou `transitions-projections`.
5. Eventos de som: click, pop, whoosh nos punches, success no resultado.
6. Renderize stills no fim de cada beat: texto legível no celular? cursor visível? nada cortado?
7. QA completo (qa-critique) e entrega.
